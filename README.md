# PC Health Monitor

A compact, responsive PC health dashboard built with HTML, CSS, and vanilla JavaScript.

Open `index.html` in a browser. No installation, build step, or dependencies are required.

## Features

- Aurora Gradient and Slate Professional themes with a remembered selection
- AI performance: decode speed, prefill speed, and context fill
- CPU, GPU, GPU 2, NVMe, and RAM temperatures
- CPU, GPU, memory, and storage utilization
- Power draw graph and component readings
- Simulated updates with pause/resume controls
- Responsive layout

All readings are demonstration data, not live hardware telemetry.
